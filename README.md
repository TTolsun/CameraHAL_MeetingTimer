# Time per Turn

종료 시각까지 남은 시간을 발표자에게 나눠 주는 타이머입니다. Windows용과 Chrome용 중 하나를 선택해 사용하세요. [GitHub 릴리스](https://github.com/TTolsun/CameraHAL_MeetingTimer/releases)

## 실행 방법

### Windows에서 실행

[Windows용 ZIP](https://github.com/TTolsun/CameraHAL_MeetingTimer/releases/latest/download/MeetingTimer-Windows.zip)을 폴더에 풀고 `MeetingTimer.bat`을 더블클릭하세요. 압축을 푼 파일은 같은 폴더에 두세요. Windows PowerShell 5.1로 실행되며 설정은 같은 폴더의 `config.json`에 저장됩니다.

### Chrome 확장 프로그램 설치

1. [Chrome용 ZIP 다운로드](https://github.com/TTolsun/CameraHAL_MeetingTimer/releases/latest/download/MeetingTimer-Chrome.zip)를 누르세요. 압축은 그대로 두세요.
2. 데스크톱 Chrome 116 이상에서 주소창에 `chrome://extensions`를 입력하고 오른쪽 위의 **개발자 모드**를 켜세요.
3. 다운로드 폴더에서 `MeetingTimer-Chrome.zip`을 확장 프로그램 페이지로 끌어다 놓으세요. 설치되면 도구 모음의 **확장 프로그램**(퍼즐 아이콘)에서 **Time per Turn**를 눌러 실행하세요. 옆의 핀을 누르면 다음부터 도구 모음에서 바로 열 수 있습니다.

끌어다 놓아도 설치되지 않으면 ZIP을 보관할 폴더에 풀고 **압축해제된 확장 프로그램을 로드합니다**를 눌러 `manifest.json`이 들어 있는 폴더를 선택하세요. 회사 정책으로 개발자 모드가 잠겨 있다면 사내 Chrome 관리자에게 설치를 요청하세요.

Chrome에서는 기본 창 아래 한 줄에 시작·일시정지, 다음, 되돌리기, 회의 설정, **Presenter bar** 버튼이 있습니다. 테마를 바꾸려면 회의 설정에서 해·달 버튼을 누르세요. 첫 발표자에게 배정한 시간을 처음 계획으로 기록합니다. 다른 발표자의 배정 시간이 처음 계획과 달라지면 기본 창 상단에 **From plan** 변경량이 표시됩니다.

**Presenter bar**를 누르면 기본 창이 최소화됩니다. 막대에는 현재 발표 순서와 남은 시간이 한 줄에 표시되고, 그 아래의 가는 선으로 진행 상황을 볼 수 있습니다. 제목 표시줄을 끌어 위치를 옮기고, 기본 창 복귀 버튼을 누르면 같은 회의로 돌아옵니다.

타이머 오른쪽 위의 **Restore default size** 버튼을 누르면 창이 380×290으로 돌아옵니다. 발표 막대에서는 크기를 바꿨을 때 같은 모양의 버튼이 오른쪽에 나타납니다(Chrome 121 이상). 두 버튼 모두 진행 중인 발표 시간을 유지합니다. Chrome 130 이상에서는 막대를 닫았다 다시 열 때마다 작은 기본 크기와 Chrome의 기본 위치로 열립니다.

아래의 창 위치, 설정 및 단축키 설명은 Windows용을 기준으로 합니다.

## 동작 방식

- **회의 종료 시각**의 기본값은 프로그램을 실행한 시각의 다음 정각입니다(14:05에 실행하면 15:00). 다만 다음 정각까지 10분이 남지 않았다면 그다음 정각으로 잡습니다(13:55에 실행하면 15:00). **Settings**에서 시간만 지정하면 됩니다. 바꾼 시간이 현재보다 이르면 **다음 날**로 안내합니다. 항상 위 표시 설정만 저장하면 종료 시각과 발표자 수가 유지됩니다.
- **발표자 수**만 입력하면 됩니다. 종료 시각까지 남은 시간을, 아직 발표를 시작하지 않은 사람 수로 똑같이 나눕니다.
- 각 발표자의 배정 시간은 **그 사람이 시작하는 순간 확정**됩니다. 따라서 앞사람이 시간을 넘기면, 아직 시작하지 않은 사람들의 몫이 그만큼 줄어듭니다. **Start**을 누르기 전에는 배정 시간이 현재 시각에 맞춰 1초 단위로 계속 다시 계산됩니다.
- 앞사람이 시간을 남기고 **Next**을 누르면, 남은 시간이 뒤 발표자 모두에게 똑같이 나뉘어 더해집니다. **Next**을 잘못 눌렀다면 **Undo** 또는 `Ctrl+Z`로 취소할 수 있습니다.
- 앞사람이 시간을 넘긴 채 **Next**을 눌러도 같은 방식으로 남은 시간을 다시 나눕니다. 종료 시각 전에는 1인당 최소 **1분**을 배정하며, 이 최소값 때문에 종료 시각을 넘길 것 같으면 위쪽 막대에 `May run past end time`이 표시됩니다. 회의 종료 시각이 지난 후 새 발표를 시작하면 계속 진행할지 확인하고, 동의하면 추가 배정 없이 초과 시간을 기록합니다.
- 위쪽 막대 가운데(현재 시각과 종료 시각 사이)에 **처음 계획 대비 변경량**(`+02:00`, `-01:30`)이 표시됩니다. 처음 계획에는 첫 발표자가 시작할 때 남은 시간을 전체 인원수로 나눈 값을 기록합니다. 예를 들어 90초가 남았을 때 두 명이 발표하면 처음 계획은 45초이고 첫 발표자에게는 최소 시간인 60초를 배정합니다.
- **발표자 수**는 종료 시각까지 남은 시간을 기준으로 상한이 정해집니다(1인당 최소 1분, 예: 남은 9분 30초면 최대 9명). 인원이나 종료 시각을 바꿔 **Save**하면 기존 발표 기록이 지워지고 선택한 인원과 종료 시각으로 1번 발표자가 시작을 기다립니다. 시간을 충분히 배정할 수 없으면 안내창에 남은 시간과 조정 방법이 표시됩니다. 취소하거나 항상 위 표시만 바꾸면 진행 중인 회의를 이어갑니다.
- 기본 창과 작업표시줄에는 현재 순서가 `Speaker 2`처럼 표시됩니다. 기본 창에는 남은 시간과 배정 시간이 표시되며, 버튼 위의 회색 분할 막대에서 발표 진행 상황을 확인할 수 있습니다.
- 배정 시간의 30% 이하가 남거나 남은 시간이 1분 이하이면 `1 min left`처럼 남은 시간을 안내합니다. 배정 시간이 지나면 `+00:00`부터 초과 시간을 표시합니다. `+00:14`까지 숫자는 평소 색을 유지하고, `+00:15`부터는 숫자에만 차분한 강조색을 적용합니다. 알림음이나 화면·작업표시줄 점멸 없이 시간 표시가 이어집니다.
- 일시정지하면 발표 시간 표시가 멈추고 일시정지 상태가 표시됩니다.
- 화면은 밝은 화면과 어두운 화면 두 가지입니다. 오른쪽 아래의 해, 달 아이콘으로 바꾸고, 선택은 다음 실행에도 유지됩니다. 설정 창은 항상 밝게 열립니다.
- **Next** 버튼은 시계가 돌고 있을 때만 나타납니다. 시작하기 전이나 일시정지 중에는 보이지 않고, `N`과 `→`도 동작하지 않습니다.
- 마지막 발표자에서 **Finish**를 누르면 새 회의가 준비되고 종료 시각은 다음 정각으로 돌아갑니다. 기본 창과 발표 막대에는 회의를 종료했다는 안내가 잠시 표시됩니다. **Undo** 버튼이나 `Ctrl+Z`로 직전 회의를 복원할 수 있습니다.
- **되돌리기 버튼 또는 `Ctrl+Z`** 는 가장 최근의 **Next**, **Finish**, **초기화**(`R`) 한 번을 취소합니다. 시계가 돌던 중이었다면, 그사이 흐른 시간은 원래 발표하던 사람에게 돌아가고 시계도 계속 돕니다. 첫 발표자의 초기화도 되돌릴 수 있습니다. `R`로 초기화할 때는 먼저 확인합니다. 발표자 수나 종료 시각을 변경하면 되돌리기가 해제됩니다.

## 화면 공유할 때 (발표 막대)

온라인 회의에서 진행자가 화면을 공유할 때는 기본 창 오른쪽 아래에서 달 아이콘 오른쪽에 있는 **발표 막대 아이콘**을 누르거나 `B`를 누릅니다. 창의 왼쪽 위 위치와 너비를 유지한 채 높이만 줄여 가로 막대로 전환합니다. 발표 막대는 항상 다른 창 위에 표시됩니다. 현재 발표자 번호는 둥근 배경으로 강조되며, **Next**을 누르면 강조가 다음 번호로 이동합니다. 한 번에 번호가 최대 5개 표시되고, 앞뒤에 번호가 더 있으면 `…`으로 표시됩니다. 전체 인원은 현재 번호 옆에 표시됩니다. 막대 안에는 **재생·일시정지**, **다음·종료**, **Undo**, **기본 창 복귀** 아이콘이 있습니다. 화면 공유 중에는 버튼 위에 마우스를 올려도 도움말이 뜨지 않습니다.

- 회의 앱에서 **창 하나가 아니라 화면 전체(또는 그 모니터)를 공유**해야 막대가 함께 보입니다. 창 하나만 공유하면 타이머는 공유 화면에 나오지 않습니다.
- 막대의 빈 부분을 드래그하면 원하는 위치에 놓을 수 있습니다. 모니터 사이로 옮기거나 화면 가장자리 가까이에 놓아도 가로 모양을 유지합니다.
- 막대에서도 단축키를 사용할 수 있습니다. 키를 쓰려면 막대를 한 번 클릭해 창을 선택해야 합니다.
- **기본 창 버튼**, `B`, `Esc` 또는 막대 더블클릭으로 돌아갑니다. 이전 창 크기·위치와 항상 위 표시 설정을 복원합니다. 막대 상태로 닫으면 다음에도 막대로 시작합니다.
- 기본 창과 설정 창의 버튼은 `Tab`·`Shift+Tab`으로 선택하고 `Enter`로 실행할 수 있습니다. 설정 창에서는 `Enter`로 저장하고 `Esc`로 취소합니다.

## 단축키

| 키 | 동작 |
|---|---|
| `Space` | 시작 / 일시정지 |
| `N` 또는 `→` | 타이머가 동작 중이면 다음 발표자를 시작하고, 마지막 발표자라면 회의를 종료합니다 |
| `R` | 확인 후 현재 발표자의 시간 초기화 |
| `Ctrl+Z` | 방금 한 다음 / 종료 / 초기화 되돌리기 |
| `S` | 설정 버튼과 같은 동작 |
| `D` | 밝은 화면 / 어두운 화면 전환. 아래쪽의 해·달 버튼으로도 선택하며, 선택은 `config.json`에 저장됩니다 |
| `B` | 발표 막대 켜기/끄기 (막대에서는 `Esc`나 더블클릭으로도 돌아갑니다) |

## 저장소 구성

| 폴더 | 역할 |
|---|---|
| `windows/` | Windows 실행용 BAT, WinForms 화면, 시간 계산 및 발표 전환 모델 |
| `chrome-extension/` | Chrome 확장 프로그램의 매니페스트, 실행 및 화면 코드, 배정 시간과 처음 계획을 계산하는 모델 |
| `scripts/` | 두 플랫폼의 배포 ZIP을 만드는 패키징 스크립트 |
| `tests/` | 시간 계산, 버튼 동작, 압축을 푼 배포본의 실행 테스트 |
| `dist/` | 로컬에서 만든 배포 ZIP |

저장소에서 Windows 앱을 실행하려면 `windows/MeetingTimer.bat`을 여세요. 두 ZIP은 루트에서 `.\scripts\Build-Release.ps1`을 실행하면 생성됩니다. 모델과 화면 테스트를 실행하는 방법은 [영문 개발자 가이드](CLAUDE.md)에 있습니다.

## 보안 사항

- 네트워크 통신, 관리자 권한, 레지스트리 변경, 파일 다운로드를 사용하지 않습니다.
- 실행 파일은 `conhost.exe`와 `powershell.exe`를 시스템 전체 경로로 호출합니다. 따라서 같은 폴더에 같은 이름의 가짜 실행 파일이 있어도 그것이 대신 실행되지 않습니다.
- PowerShell은 이 프로세스에 한해서만 `-ExecutionPolicy RemoteSigned`로 실행됩니다. 메일이나 다운로드로 받은 사본은 서명되어 있거나, 내용을 확인한 뒤 직접 차단을 해제해야 실행됩니다.
- `config.json`은 신뢰할 수 없는 데이터로 취급합니다. 크기를 제한하고, JSON 객체만 받으며, 모든 값의 타입과 범위를 검사합니다. 예상과 다른 값이 있으면 기본값을 사용합니다.
