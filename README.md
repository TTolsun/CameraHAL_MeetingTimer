# CameraHAL_MeetingTimer

CameraHAL 주간 미팅에서 쓰는 작은 발표 타이머입니다. 남은 회의 시간을 발표자 수만큼 똑같이 나누고, 현재 발표자와 남은 시간을 보여 줍니다. 창은 항상 다른 창 위에 표시됩니다.

Windows 10/11에 기본으로 들어 있는 Windows PowerShell 5.1로 동작하므로, 따로 설치할 것은 없습니다.

## 실행 방법

`CameraHAL_MeetingTimer.bat`을 더블클릭합니다.

창은 화면 오른쪽 아래 구석에 뜹니다.

> **Release에서 zip으로 내려받은 경우**
> Windows는 인터넷에서 받은 스크립트의 실행을 막습니다. 압축을 풀기 **전에** zip 파일을 우클릭하고 **속성 → 일반 탭 아래쪽의 "차단 해제"** 를 체크한 뒤 확인을 누르세요. 이미 압축을 풀었다면, 내용을 확인한 다음 그 폴더에서 아래 명령을 실행하면 됩니다.
>
> ```powershell
> Unblock-File .\CameraHAL_MeetingTimer.ps1
> ```

## 동작 방식

- **회의 종료 시각**의 기본값은 프로그램을 실행한 시각의 다음 정각입니다(14:05에 실행하면 15:00). 다만 다음 정각까지 10분이 남지 않았다면 그다음 정각으로 잡습니다(13:55에 실행하면 15:00). **설정**에서 시간만 지정하면 됩니다. 바꾼 시간이 현재보다 이르면 **다음 날**로 안내합니다. 항상 위 표시 설정만 저장하면 종료 시각과 발표자 수가 유지됩니다.
- **발표자 수**만 입력하면 됩니다. 종료 시각까지 남은 시간을, 아직 발표를 시작하지 않은 사람 수로 똑같이 나눕니다.
- 각 발표자의 배정 시간은 **그 사람이 시작하는 순간 확정**됩니다. 따라서 앞사람이 시간을 넘기면, 아직 시작하지 않은 사람들의 몫이 그만큼 줄어듭니다. **시작**을 누르기 전에는 배정 시간이 현재 시각에 맞춰 1초 단위로 계속 다시 계산됩니다.
- 앞사람이 시간을 남기고 **다음**을 누르면, 남은 시간이 뒤 발표자 모두에게 똑같이 나뉘어 더해집니다. **다음**을 잘못 눌렀다면 **되돌리기** 또는 `Ctrl+Z`로 취소할 수 있습니다.
- 앞사람이 시간을 넘긴 채 **다음**을 눌러도 같은 방식으로 남은 시간을 다시 나눕니다. 종료 시각 전에는 1인당 최소 **1분**을 배정하며, 이 최소값 때문에 종료 시각을 넘길 것 같으면 위쪽 막대에 `종료 시각 초과 예상`이 표시됩니다. 회의 종료 시각이 지난 후 새 발표를 시작하면 계속 진행할지 확인하고, 동의하면 추가 배정 없이 초과 시간을 기록합니다.
- 위쪽 막대 가운데(현재 시각과 종료 시각 사이)에 **처음 계획 대비 변경량**(`+02:00`, `-01:30`)이 표시됩니다. 처음 계획은 각 회의에서 첫 발표자가 시작할 때의 1인당 시간입니다.
- **발표자 수**는 종료 시각까지 남은 시간을 기준으로 상한이 정해집니다(1인당 최소 1분, 예: 남은 9분 30초면 최대 9명). 인원이나 종료 시각을 바꿔 **저장**하면 기존 발표 기록이 지워지고 선택한 인원과 종료 시각으로 1번 발표자가 시작을 기다립니다. 시간을 충분히 배정할 수 없으면 안내창에 남은 시간과 조정 방법이 표시됩니다. 취소하거나 항상 위 표시만 바꾸면 진행 중인 회의를 이어갑니다.
- 기본 창과 작업표시줄에는 현재 순서가 `발표자 2`처럼 표시됩니다. 기본 창에는 남은 시간과 배정 시간이 표시되며, 버튼 위의 회색 분할 막대에서 발표 진행 상황을 확인할 수 있습니다.
- 배정 시간의 30% 이하가 남거나 남은 시간이 1분 이하이면 `1분 남았어요`처럼 남은 시간을 안내합니다. 배정 시간이 지나면 `+00:00`부터 초과 시간을 표시합니다. `+00:14`까지 숫자는 평소 색을 유지하고, `+00:15`부터는 숫자에만 차분한 강조색을 적용합니다. 알림음이나 화면·작업표시줄 점멸 없이 시간 표시가 이어집니다.
- 일시정지하면 발표 시간 표시가 멈추고 일시정지 상태가 표시됩니다.
- 화면은 밝은 화면과 어두운 화면 두 가지입니다. 오른쪽 아래의 해, 달 아이콘으로 바꾸고, 선택은 다음 실행에도 유지됩니다. 설정 창은 항상 밝게 열립니다.
- **다음** 버튼은 시계가 돌고 있을 때만 나타납니다. 시작하기 전이나 일시정지 중에는 보이지 않고, `N`과 `→`도 동작하지 않습니다.
- 마지막 발표자에서 **종료**를 누르면 새 회의가 준비되고 종료 시각은 다음 정각으로 돌아갑니다. 기본 창과 발표 막대에는 회의를 종료했다는 안내가 잠시 표시됩니다. **되돌리기** 버튼이나 `Ctrl+Z`로 직전 회의를 복원할 수 있습니다.
- **되돌리기 버튼 또는 `Ctrl+Z`** 는 가장 최근의 **다음**, **종료**, **초기화**(`R`) 한 번을 취소합니다. 시계가 돌던 중이었다면, 그사이 흐른 시간은 원래 발표하던 사람에게 돌아가고 시계도 계속 돕니다. 첫 발표자의 초기화도 되돌릴 수 있습니다. `R`로 초기화할 때는 먼저 확인합니다. 발표자 수나 종료 시각을 변경하면 되돌리기가 해제됩니다.

## 화면 공유할 때 (발표 막대)

온라인 회의에서 진행자가 화면을 공유할 때는 기본 창 오른쪽 아래에서 달 아이콘 오른쪽에 있는 **발표 막대 아이콘**을 누르거나 `B`를 누릅니다. 기본 위치는 현재 모니터 아래쪽이며, Windows 작업표시줄을 가리지 않고 다른 창 위에 표시됩니다. 발표자 수와 남은 시간에 관계없이 막대 크기는 일정합니다. 카메라 아이콘이 현재 발표자의 번호를 가리키며, **다음**을 누르면 다음 번호로 이동합니다. 한 번에 번호가 최대 5개 표시되고, 앞뒤에 번호가 더 있으면 `…`으로 표시됩니다. 전체 인원은 현재 번호 옆에 표시됩니다. 막대 안에는 **재생·일시정지**, **다음·종료**, **되돌리기**, **기본 창 복귀** 아이콘이 있습니다. 화면 공유 중에는 버튼 위에 마우스를 올려도 도움말이 뜨지 않습니다.

- 회의 앱에서 **창 하나가 아니라 화면 전체(또는 그 모니터)를 공유**해야 막대가 함께 보입니다. 창 하나만 공유하면 타이머는 공유 화면에 나오지 않습니다.
- 막대의 빈 부분을 드래그하면 가장 가까운 **위·아래·왼쪽·오른쪽** 가장자리에 붙습니다. 위아래에서는 가로 막대, 좌우에서는 세로 막대로 표시됩니다. 다른 모니터로 드래그할 수도 있습니다. 선택한 방향은 다음 실행에도 유지됩니다.
- 막대에서도 단축키를 사용할 수 있습니다. 키를 쓰려면 막대를 한 번 클릭해 창을 선택해야 합니다.
- **기본 창 버튼**, `B`, `Esc` 또는 막대 더블클릭으로 돌아갑니다. 이전 창 크기·위치와 항상 위 표시 설정을 복원합니다. 막대 상태로 닫으면 다음에도 막대로 시작합니다.
- 기본 창과 설정 창의 버튼은 `Tab`·`Shift+Tab`으로 선택하고 `Enter`로 실행할 수 있습니다. 설정 창에서는 `Enter`로 저장하고 `Esc`로 취소합니다.

## 단축키

| 키 | 동작 |
|---|---|
| `Space` | 시작 / 일시정지 |
| `N` 또는 `→` | 타이머가 동작 중이면 다음 발표자를 시작하고, 마지막 발표자라면 회의를 종료합니다 |
| `R` | 확인 후 현재 발표자의 시간 초기화 |
| `Ctrl+Z` | 방금 한 다음 / 종료 / 초기화 되돌리기 |
| `S` | 설정 버튼과 같은 동작 |
| `D` | 밝은 화면 / 어두운 화면 전환. 아래쪽의 해·달 버튼으로도 선택하며, 선택은 `config.json`에 저장됩니다 |
| `B` | 발표 막대 켜기/끄기 (막대에서는 `Esc`나 더블클릭으로도 돌아갑니다) |

## 파일 구성

| 파일 | 용도 |
|---|---|
| `CameraHAL_MeetingTimer.bat` | 실행 파일(PowerShell 콘솔 창을 숨기고 타이머를 띄웁니다) |
| `CameraHAL_MeetingTimer.ps1` | 타이머 본체(WinForms 화면) |
| `config.json` | 저장된 설정입니다. 설정을 저장하거나 화면을 바꾸거나 프로그램을 닫을 때 만들어지며, git에는 올리지 않습니다 |
| `tests\TimeModel.Tests.ps1` | 가짜 시계로 시간 계산, 표시 기준, 카메라 이동, 도킹 좌표를 검사합니다 |
| `tests\Ui.Tests.ps1` | 네이티브 버튼·키보드·설정·가로/세로 배치를 검사하고 선택적으로 화면 이미지를 생성합니다. 개발용 테스트는 릴리스 zip에서 제외됩니다 |

## 보안 사항

- 네트워크 통신, 관리자 권한, 레지스트리 변경, 파일 다운로드를 사용하지 않습니다.
- 실행 파일은 `conhost.exe`와 `powershell.exe`를 시스템 전체 경로로 호출합니다. 따라서 같은 폴더에 같은 이름의 가짜 실행 파일이 있어도 그것이 대신 실행되지 않습니다.
- PowerShell은 이 프로세스에 한해서만 `-ExecutionPolicy RemoteSigned`로 실행됩니다. 메일이나 다운로드로 받은 사본은 서명되어 있거나, 내용을 확인한 뒤 직접 차단을 해제해야 실행됩니다.
- `config.json`은 신뢰할 수 없는 데이터로 취급합니다. 크기를 제한하고, JSON 객체만 받으며, 모든 값의 타입과 범위를 검사합니다. 예상과 다른 값이 있으면 기본값을 사용합니다.
